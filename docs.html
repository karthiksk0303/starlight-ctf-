DOCUMENT 04-A / AUTHENTICATION

Protocol notes.

Recovered notes from the identity gateway engineering team.

01 / TOKEN FORMAT

Bearer credentials

After login, the gateway issues a JSON Web Token (JWT). A JWT commonly contains three Base64URL-encoded segments separated by dots: a header, a payload, and a signature.

header.payload.signature
02 / ACCESS POLICY

Clearance claims

The archive endpoint checks the role claim. Cadet accounts should not have access to restricted archives.

Engineering reminder: decoded data is not the same as verified data. Always validate the signature and relevant claims before trusting a token.

03 / AVAILABLE ENDPOINTS
  • POST /api/login — issue a cadet token
  • GET /api/profile — inspect token identity
  • GET /api/archive — restricted archive
FIELD NOTE

When a system makes a decision based on a token, ask: what verifies the claims came from a trusted issuer?
